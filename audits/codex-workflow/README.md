# Codex Workflow Audits

This directory preserves dated, evidence-backed reviews of Andy's Codex working
patterns. The reusable workflow lives in
`moon-stone00/skills/codex-workflow-audit/`; this directory owns only run history
and decisions.

## Layout

```text
YYYY-MM-DD/
└── scope-slug/
    └── report.md
```

Use a scope slug such as `september`, `october-to-date`, or `last-14-days`.
Multiple audits may share a run date when their evidence windows differ.

Each report should record its evidence window, authorized scope, findings,
proposals, limitations, and later decisions. Update `index.md` after every run.
Reports must distinguish a drafted proposal from an approved or implemented
change.
